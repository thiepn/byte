# Byte v1.0 Product Contract

Status: frozen for v1 development.

Byte is a Windows-first, private, lightweight desktop companion. The primary product is a cute, customizable character; the secondary product is understandable system-health assistance.

## Priorities

1. Cute.
2. Personal.
3. Alive.
4. Helpful.
5. Lightweight.
6. Unobtrusive.

Safety, privacy, correctness, and reliability override aesthetic priority when they conflict.

## V1 system concepts

Byte may explain CPU, memory pressure, best-effort thermal state, battery, storage, network activity, and a likely culprit application when useful. The normal UI does not expose engineering sensor tables, per-core dashboards, voltage rails, SMART diagnostics, benchmarks, or fan controls.

## V1 companion scope

- Characters: Byte, Mochi, Pip, Kiwi.
- Habitats: Meadow, Cozy Desk, Bedroom, Space, Aquarium, Rooftop.
- Personalities: Chill, Curious, Energetic.
- Display modes: Habitat, Perch, Mini, Edge, Tray.
- Modular palettes, headwear, accessories, props, and fixed-slot habitat decoration.
- Anonymous typing/click/scroll reactions without key-content collection.

## Explicit non-goals

Byte is not a PC cleaner, RAM optimizer, registry cleaner, driver updater, fan controller, benchmark suite, antivirus, Task Manager replacement, productivity tracker, cloud service, social product, or mandatory virtual-pet maintenance game.

## Privacy

No account, cloud dependency, ads, analytics, behavioral telemetry, key logging, process-name upload, or background network service. Native notifications are local OS output. Release/update checks are the expected production network activity.

## Release platform

Windows 11 x64 is the v1 certification target. Windows 10 is best effort. macOS and Linux are post-v1.
